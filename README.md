# 10 printf() and scanf() Examples in C

Beginner-friendly C programs demonstrating `printf()` and `scanf()`.

## Programs
1. Print Name
2. Addition
3. Subtraction
4. Multiplication
5. Division
6. Square of a Number
7. Area of Rectangle
8. Average of Three Numbers
9. Find Age
10. Celsius to Fahrenheit

## How to run
Example:
```bash
gcc 02_addition.c -o addition
./addition
```
