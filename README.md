# C printf() and scanf() - 10 Beginner Programs

This repository contains 10 simple C programs for practicing `printf()` and `scanf()`.

## Programs
1. Hello World
2. Print Name
3. Input and Print Name
4. Add Two Numbers
5. Subtract Two Numbers
6. Multiply Two Numbers
7. Divide Two Numbers
8. Student Details
9. Area of Rectangle
10. Simple Calculator

## How to run
Compile a program:
```bash
gcc 04_add_two_numbers.c -o add
```

Run it:
```bash
./add
```
